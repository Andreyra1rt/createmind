# Telegram Web App Portfolio & Lead Generator

Стильное, легкое одностраничное мини-приложение (Telegram Web App) для презентации услуг разработки ИИ-решений / веб-приложений и сбора заявок.

## ✨ Особенности
* **Интеграция с темой Telegram**: Автоматически подстраивается под светлую или темную тему мессенджера.
* **Glassmorphism дизайн**: Использование размытых фонов и градиентов для премиального внешнего вида.
* **WOW-эффект**: Интерактивные 3D-карточки услуг с плавным наклоном (Tilt Effect).
* **Удобство**: Поддержка нативной кнопки Telegram (MainButton) при заполненной форме.
* **Гибкая отправка**: 
  - Через `tg.sendData()` (если открыто как Keyboard WebApp).
  - Через прямое перенаправление в ЛС к разработчику с автозаполненным текстом (с помощью `tg.openTelegramLink()`).

## 🚀 Быстрый старт (Локальное тестирование)

1. Откройте файл `app.js` и впишите ваш юзернейм в Telegram в константу `DEVELOPER_USERNAME`:
   ```javascript
   const DEVELOPER_USERNAME = 'ваш_юзернейм_без_собачки';
   ```

2. Запустите локальный веб-сервер в этой директории. Например, с помощью Python:
   ```bash
   python3 -m http.server 8000
   ```
   Или с помощью Node.js (если установлен `http-server` или `live-server`):
   ```bash
   npx http-server .
   ```

3. Чтобы Telegram Web App открылся внутри Telegram, он должен быть доступен по защищенному протоколу HTTPS. Для локального тестирования используйте **ngrok** или **localtunnel**:
   ```bash
   # Запуск ngrok для порта 8000
   ngrok http 8000
   ```
   Скопируйте полученную ссылку, начинающуюся с `https://` (например, `https://xxxx.ngrok-free.app`).

## 🤖 Как привязать Web App к Telegram-боту

Чтобы пользователи могли запускать ваше приложение прямо из Telegram:

1. Перейдите к [@BotFather](https://t.me/BotFather) в Telegram.
2. Создайте нового бота через `/newbot` или выберите существующего через `/mybots`.
3. Настройте кнопку меню бота (Menu Button):
   * Выберите вашего бота в списке.
   * Перейдите в **Bot Settings** -> **Menu Button** -> **Configure Menu Button**.
   * Отправьте BotFather ссылку `https://...` (которую вы получили от ngrok или хостинга).
   * Введите название кнопки (например, `⚡ Заказать`).
4. **Готово!** Теперь в чате с ботом в левом нижнем углу появится кнопка запуска вашего Web App.

## 🌐 Публикация на бесплатный хостинг

Для постоянной работы приложения его нужно загрузить на любой хостинг статических сайтов. Рекомендуемые бесплатные платформы:
* **Vercel** (`npx vercel`)
* **Netlify**
* **GitHub Pages**
* **Firebase Hosting**

После загрузки замените локальную ссылку в BotFather на постоянную ссылку хостинга.
